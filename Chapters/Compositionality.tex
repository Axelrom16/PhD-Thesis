\chapter{Compositionality}\label{ch:compositionality}
%************************************************

The ability to decompose complex environments into foundational, reusable elements and seamlessly recombine them to understand or generate novel scenarios is a characteristic of human cognition, especially in human language comprehension and visual perception \cite{sinha2024surveycompositionallearningai}. This principle, known as \textbf{compositionality}, is tightly connected to the ability of a model to generalize over unobserved situations. While originally rooted in linguistics and cognitive science, the field of compositional generalization is currently gaining attention in artificial intelligence, motivated by real-world applications \cite{lin2023surveycompositionalgeneralizationapplications}. Compositional learning represents a paradigm shift from models that merely memorize patterns to those that actively extract and manipulate independent semantic factors. \\
The primary interest in compositional learning stems from its potential to solve one of the most persistent bottlenecks in deep learning: generalization. A model effectively learned from some specific examples is expected to be able to consistently handle unknown combinations of those known parts \cite{ram2024makesmodelscompositionaltheoretical}. However, standard neural architectures frequently fail when confronted with out-of-distribution (OOD) scenarios that require systematic reasoning over unseen combinations of familiar concepts. \\
\\
Compositional generalization is broadly recognized as a key ingredient for visual generative models, actively enabling them to generate novel combinations of known visual concepts \cite{farid2026drivescompositionalgeneralizationimportance}. The connection between generative models and compositionality lies in aligning the internal generation process of the model with the compositional structure of reality. Recent studies reveal that continuous representations in generative models enforce a smoother latent structure that permits continuous interpolation between elements, significantly benefiting compositional generation when compared to discrete token-based modelling. If a generative model can learn isolated representations, such as additive compositions with occlusion, or specific visual attributes like the shape, translation, and color of an object in pixel space, it can accurately reconstruct and generalize these features to entirely unseen data distributions \cite{wiedemer2023compositionalgeneralizationprinciples}. Ultimately, integrating compositional priors into generative models not only mitigates their memorization on training datasets, but unlocks their ability to synthesize unseen combinations.


\section{Object-Centric Learning} 
Slot Attention (SA) \cite{locatello2020objectcentriclearningslotattention} is a differentiable interface between image features and a set of variables called slots. This method maps a set of $N$ image patches with dimension $D_{input}$, called image features $\mathbf{F}\in\mathbb{R}^{N\times D_{input}}$, to a set of $K$ output vectors of size $D_{slot}$ called slots, $\mathbf{S}\in \mathbb{R}^{K\times D_{slot}}$. Each vector of the slots can describe an object or element in the input image. The process of binding a part of the image to the slots is performed via iterative refinement over $T$ steps, where in each iteration the slots compete via a softmax attention mechanism to explain parts of the input. Slot representations are initialised randomly with a Gaussian distribution. \\
If we define some learnable linear transformations $k,q$, and $v$ to map input features and slots to a common dimension $D$, we can define: 
\begin{equation}
    \mathbf{A}_{i,j} = \frac{e^{\mathbf{M}_{i,j}}}{\sum_l e^{\mathbf{M}_{i,l}}}, \; \text{where} \; \mathbf{M}=\frac{1}{\sqrt{D}} k(\mathbf{F})\cdot q(\mathbf{S})^T \in \mathbb{R}^{N\times K}
\end{equation}
The normalisation in the attention ensures that attention coefficients sum to one for each individual input feature vector. The update for the slots can be defined as: 
\begin{equation}
    \mathbf{U} = \mathbf{W}^T\cdot v(\mathbf{F}) \in \mathbb{R}^{K\times D} \; \text{where} \; \mathbf{W}_{i,j} = \frac{\mathbf{A}_{i,j}}{\sum_{l=1}^N \mathbf{A}_{l,j}}.
\end{equation}
Slot updates are performed via a Gated Recurrent Unit (GRU) and a small MLP layer with ReLU and residual connections, applied independently to each slot using shared parameters. \\
Once the slot representations are learned, they can be used for several downstream tasks. Some examples in the original paper \cite{locatello2020objectcentriclearningslotattention} are 
\begin{itemize}
    \item \textbf{Object discovery}: SA can be used as a part of an autoencoder model for unsupervised object discovery. The encoder encodes the image in a set of slots, and the decoder reconstructs the original image. In this case, the slots act as a representation bottleneck. They proposed the use of a spatial broadcast decoder, which removes the upsampling deconvolutions. This new decoder first broadcasts the latent vector across the space (height and width of the image), appends fixed coordinate channels, and applies a fully convolutional network to produce a final tensor with 4 channels, 3 for RGB and the alpha channel. 
    \item \textbf{Set prediction}: In this scenario, we have an input image and a set of prediction targets. The main challenge is that the output order in SA is random, so there are $K!$ possible equivalent representations for a set of $K$ slots. In this case, they proposed to apply for each slot an MLP with shared parameters between slots. To overcome the problem of different prediction and label orders, they used a matching algorithm in the loss computation. 
\end{itemize}
The next step is the \textbf{Contrastive Object-centric Diffusion Alignment} (CODA) \cite{nguyen2026improvedobjectcentricdiffusionlearning}, a diffusion-based OCL where the slots ($\mathbf{s}$) are extracted using Slot Attention over DINOv2 features and decoded with a pretrained Stable Diffusion v1.5 model. An illustration of the pipeline is presented in Figure \ref{fig:coda}.  
\begin{figure}
    \centering

    \caption{Overview of the pipeline of the CODA method.}
    \label{fig:coda}
\end{figure} 
This method introduces three key components to improve the disentanglement and the alignment between the slot and the visual components of the image. 
\begin{itemize}
    \item \textbf{Register Slots}. The idea is to define a set of input-independent register slots to capture the residual information, such as the background, which is usually entangled with all the slots. They proposed this method based on some experiments where reconstruction from the full set of slots resembles the input image, but using only a small set of slots, the result is a distorted image, which is not consistent with an ideal OCL model. These register slots ($\mathbf{\bar r}$) are defined as frozen embeddings by encoding with a pretrained text encoder a sequence of \texttt{PAD} tokens. 
    \item \textbf{Finetune of Cross-Attention}. Since we are using a pre-trained SD model trained on large-scale image-text pairs, using the slot embeddings directly will introduce a bias, as it expects text embeddings. They proposed to only finetune the key, value, and output projections in cross-attention layers, which allows the model to better align slots with visual content and preserve the expressiveness of the pretrained diffusion backbone. Also, this approach is computationally and memory efficient. 
    \item \textbf{Contrastive Alignment Loss}. Using only the diffusion loss, the model does not have explicit supervision to ensure that slots capture concepts present in the image. They proposed a contrastive alignment objective that aligns slots with image content while discouraging overlap between different slots. The idea is to assign high likelihood to the correct slot representations and low likelihood to negative slots ($\mathbf{\tilde s}$), which are created as a random shuffle between slots of two different images. 
\end{itemize} 
The overall training objective of CODA is defined as 
\begin{equation}
    \mathcal{L}(\phi, \theta) = \mathcal{L}_{dm}(\phi,\theta) + \lambda_{cl}\mathcal{L}_{cl}(\phi),
\end{equation}
where $\phi$ are the parameters of Slot Attention, $\theta$ the parameters of the diffusion models and $\lambda_{cl}$ controls the trade-off between the denoising and contrastive terms. The losses are defined as 
\begin{equation}
    \mathcal{L}_{dm}(\phi,\theta) = \mathbb{E}_{\epsilon, t, (\mathbf{x},\mathbf{s})} \left[ ||\epsilon - \epsilon_{\theta}(\mathbf{x}_t, t, (\mathbf{s},\mathbf{\bar r}))||^2_2 \right]
\end{equation}
\begin{equation}
    \mathcal{L}_{cl}(\phi) = -\mathbb{E}_{\epsilon, t, (\mathbf{x},\mathbf{\tilde s})} \left[ ||\epsilon - \epsilon_{\theta}(\mathbf{x}_t, t, (\mathbf{\tilde s},\mathbf{\bar r}))||^2_2 \right]
\end{equation}
